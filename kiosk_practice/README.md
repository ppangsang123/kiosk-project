# 키오스크 연습실

고령층이 여러 식당 키오스크를 미리 연습할 수 있는 웹 앱입니다. 식당 유형을 선택하면 메뉴판과 옵션 선택지가 바뀌고, 매 연습마다 무작위 목표 주문이 제시됩니다.

## 탐구 주제 연결

- 대주제: 키오스크는 누구를 위한 매체인가
- 활동 목적: 키오스크 사용이 낯선 어르신이 식당별 주문 과정을 부담 없이 연습하도록 돕기
- 데이터 활용: 교육 전, 교육 직후, 재방문 기록을 비교해 연습 프로그램의 효과 확인

## 현재 포함된 식당 유형

- 카페: 커피와 음료 주문 연습
- 햄버거 가게: 버거 단품/세트 주문 연습
- 치킨 가게: 치킨 포장/매장 주문 연습

## 수집되는 지표

- 식당 유형
- 무작위로 제시된 목표 주문
- 참여자 구분: 어르신, 학생, 기타
- 연습 회차: 교육 전, 교육 직후, 재방문
- 목표 주문과 일치했는지 여부
- 선택 메뉴, 옵션, 결제 방식
- 주문 완료까지 걸린 시간
- 도움 버튼 사용 횟수
- 이전 버튼 사용 횟수

## 분석 예시

- 교육 전후 평균 주문 시간 비교
- 교육 전후 목표 주문 성공률 비교
- 식당 유형별 성공률 비교
- 식당 유형별 도움 버튼 사용 횟수 비교
- 학생과 어르신 집단의 성공률과 되돌아감 횟수 비교
- 재방문 시 사용 능력이 유지되는지 확인

## 다른 기기에서 접속하기

같은 와이파이 또는 같은 네트워크에 연결된 기기에서 접속할 수 있습니다.

1. `start_site.bat`을 실행합니다.
2. 실행 창에 표시되는 `Other devices on the same Wi-Fi` 주소를 확인합니다.
3. 휴대폰이나 태블릿 브라우저에서 해당 주소로 접속합니다.

현재 이 PC에서 확인된 주소 예시:

`http://10.223.66.111:8080/kiosk_practice/index.html`

학교나 공공 와이파이에서는 보안 설정 때문에 같은 네트워크여도 접속이 막힐 수 있습니다. 이 경우 방화벽에서 8080번 포트를 허용하거나, GitHub Pages 같은 공개 호스팅으로 배포해야 합니다.
